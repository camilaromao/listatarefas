## Lista de tarefas

Projeto desenvolvido com HTML, CSS e JavaScript.

A aplicação permite marcar tarefas já feitas, exclui-las e até adicinar novas tarefas. Marca com um risco as tarefas concluidas. Caso o usuário clique no botão de +, sem preencher o quadro de novas tarefas é gerado uma mensagem informando para escrever a nova tarefa.
